# Atividade Js

Desafios avaliativos de JavaScript

Serão feitos 2 desafios avaliativos, valendo 20 pontos.

Não serão aceitos sistemas por IA.

Desafios feitos com IA, nota 0 e Recuperação.

Desafio 1

Objetivo:

Cirar um sistema onde o usuário consiga:
- cadastrar produto
- visualizar produtos cadastrados
- remover produtos
- conta quantos produtos existem.

O sistema deve possuir:

- input para nome do produtos
- botão de adicionar
- lista de produtos
- contador de produtos


Desafio 2


Criar uma lista de presença de alunos

Criar:
- botão para adicionar alunos
- mostrar lista na tela
- permita marcar presença
- contar - Presentes e Ausentes.

O sistema deve impedir nomes vazios, atualiar total de alunos, atualizar presentes e ausentes.


Vão utilizar no JavaScript:

-for
-array
-querySelection
-addEventListner
-createElement
-classList.toggle
Além de manipular DOM
